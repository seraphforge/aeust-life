# 隱私與資料生命週期

## V0.1 本機狀態

表單不要求登入、學號、姓名、電話、Email、位置或學校密碼。只有 UUID、類型、內容與 UTC 時間入資料庫。不使用分析追蹤、第三方字型、cookie 或瀏覽器 localStorage 保存回饋。

前端失敗時只保留目前頁面記憶體中的輸入；重新整理會失去內容。成功後清空。匿名回饋不公開顯示，不能個別回覆。請勿在自由文字輸入個資。

離線 adapter 寫入 `.local/feedback.sqlite`，Wrangler 寫入 `.wrangler/` 的本機資料。兩者是不同資料庫，切換不會自動移轉。只有開發者本機可見，本機回饋不會傳給 Nagi 或雲端。

## 正式部署前必須確定

- 指定資料管理者與私人聯絡管道。
- 明確保存期限（建議從 90 天開始評估，但目前**未實作自動刪除**），包含備份與基礎設施日誌。
- 建立到期清除、誤填個資刪除與事故處理程序；定期確認清除實際執行。
- 限縮 Cloudflare 帳號與 D1 管理權限，不讓回饋內容出現在公開 Issue／log。
- 揭露 Cloudflare 的連線資訊處理、可用的地區設定與適用隱私條款。
- 更新網站回饋頁的公開隱私說明，完成後才開放一般學生送出。

本文件是開發期行為與待辦紀錄，不宣稱已完成正式服務的法律／隱私審查。
